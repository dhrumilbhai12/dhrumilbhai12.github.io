A free form builder with unlimited responses

Many popular form tools have free plans that cap how many responses you can collect each month, then ask you to upgrade. This builder takes a different approach: it gives you the form itself as a standalone HTML file. You host it, so there is nothing for us to count and no monthly limit.

How to build and publish your form

  1. Add questions — short text, long text, multiple choice, rating or email. Reorder them with the arrows and mark any as required.
  2. Preview — the right-hand panel shows the form exactly as respondents will see it, one question at a time.
  3. Export — click Export as HTML to download a single file with no dependencies.
  4. Connect responses — open the file and set ENDPOINT to a URL that accepts JSON (Formspree, Google Apps Script, a Cloudflare Worker…).
  5. Publish — upload the file to Cloudflare Pages, GitHub Pages, Netlify or your own website and share the link.

Why one question at a time?

Showing a single question per screen keeps people focused, works well on phones and makes long forms feel shorter. Respondents can press Enter to move on and go back to change an answer.

Plan a form people can finish

Before adding fields, decide what decision or next step the answers should support. Every question asks the respondent to spend attention, so remove questions that do not help you act on the response. Ask one clear thing at a time, use plain labels, and explain why you need sensitive details. For multiple choice, make options distinct and include an “Other” choice when the list cannot cover every reasonable answer.

Test the exported form on a phone as well as a computer. A short preview session can catch confusing wording, missing choices and questions that are difficult to answer with a small keyboard. Decide where responses should go before publishing: the file can be hosted independently, but collecting submissions requires an endpoint you control or a service you trust. Try a test submission and check the received data before sharing the live form.

Frequently asked questions

Is this form builder really free with unlimited responses?

Yes. You build the form here and export it as a single HTML file that you host anywhere (Cloudflare Pages, GitHub Pages, Netlify, your own site). We don't count or cap responses, because they never pass through us.

How do I collect the responses?

The exported file has one setting at the top, ENDPOINT. Point it at any URL that accepts JSON — for example a Formspree form, a Google Apps Script web app, or a small Cloudflare Worker — and each submission is posted there. Without an endpoint, the answers are shown on screen so you can test.

Where are my drafts saved?

In your browser's local storage on this device. Nothing is sent to a server. Clearing your browser data removes the draft, so export a copy when you're done.

Which question types are supported?

Short text, long text, multiple choice, a 1–5 rating and email, each with an optional Required toggle. Video-answer questions are coming in the full Tinkro app.

Can I change how the form looks?

The exported file is plain HTML and CSS, so you can edit colours, fonts and copy in any text editor.
