What this robots.txt generator does

A robots.txt file gives cooperating crawlers instructions about which URL paths they may request. It is public and does not secure private content. A Disallow rule does not guarantee that a URL will disappear from search results, especially if other pages link to it. Use authentication for private material, and use a page-level noindex directive when you need a crawler that can access a page to avoid indexing it.

How to use this tool

  1. Read the fields and enter or paste the information you want to review.
  2. Adjust the available options to match the page, text or crawler setup you are working on.
  3. Review the generated counts, preview or report. Check any warning against your actual goal.
  4. Copy, download or apply the result, then verify it on the destination page or in your normal workflow.

Practical tips

  • Start with the least restrictive rule set that reflects your crawl needs.
  • Use paths relative to the site root, such as /drafts/; do not paste a full page URL into a path field.
  • Check that important CSS, JavaScript and image files remain crawlable when search engines need them to render a page.
  • Add a sitemap URL as a complete HTTPS address.
  • Test the downloaded file on the domain root and keep a copy of the prior version before replacing production rules.

Interpreting your results

Before publishing rules, test them against the exact paths you intend to control. A broad Disallow rule can prevent crawlers from fetching content needed to understand a page, and rules apply to a host rather than to an entire brand across every subdomain. If your website has multiple hosts, each one needs its own robots.txt file. Directives for named bots are requests, and user agents can change over time. Keep the file easy to audit, document why unusual exclusions exist, and revisit rules after a redesign so old development paths do not accidentally block useful public pages.

Frequently asked questions

Does robots.txt keep pages private?

No. It is a public request for cooperating crawlers. Protect sensitive pages with authentication or access controls.

Where should robots.txt live?

At the root of the hostname, for example https://example.com/robots.txt. A file inside a subfolder does not govern the whole site.

Does Disallow remove a page from search?

Not necessarily. Crawlers may still know a URL exists. Use appropriate indexing directives and access controls for your actual goal.

What is a user-agent group?

A group starts with User-agent and applies the following rules to that named crawler until another group begins.

Do all crawlers follow crawl-delay?

No. Crawler support varies, and some major crawlers ignore that directive. Check each crawler’s current documentation.
